# TGBot — Telegram-бот для Minecraft 1.16.5 (Fabric)

Мод для Minecraft Fabric 1.16.5, который подключает Telegram-бота к игре.
Позволяет управлять игроком удалённо через Telegram.

## Установка

1. Установи [Fabric Loader](https://fabricmc.net/) для Minecraft 1.16.5
2. Скачай [Fabric API](https://modrinth.com/mod/fabric-api) и положи в `mods/`
3. Скачай `tgbot-fabric-1.16.5-1.0.0.jar` из Releases и положи в `mods/`
4. Запусти Minecraft

## Настройка

1. Создай бота в Telegram через **@BotFather**, скопируй токен
2. В Minecraft нажми **P** → открывается меню настроек бота
3. Вставь токен, нажми «▶ Старт»
4. Напиши боту любое сообщение в Telegram — он автоматически определит Chat ID
5. Выбери режим и сохрани

### Режимы

| Режим | Описание |
|-------|----------|
| **1 — Сервер** | Ограниченный. Только движение, обзор и базовые команды. Лимит 2 мин на движение для не-админов |
| **2 — Мир** | Полный доступ. Телепортация, выдача предметов, смена гейммода |

### Админы

Telegram ID админов вводятся через запятую в настройках.
Админы не подчиняются лимиту 2 минут на движение (режим 1).

## Команды Telegram-бота

### Общие команды (оба режима)

| Команда | Описание |
|---------|----------|
| `/help` | Список доступных команд |
| `/status` | Состояние игрока (HP, голод, координаты, мир) |
| `/say <текст>` | Написать в чат Minecraft |
| `/move forward\|back\|left\|right\|stop` | Движение |
| `/look <yaw> <pitch>` | Повернуть камеру |
| `/jump` | Прыжок |
| `/stop` | Остановить всё |

### Команды только для режима 2 (Мир)

| Команда | Описание |
|---------|----------|
| `/tp <x> <y> <z>` | Телепортация |
| `/give <предмет> [кол-во]` | Выдать предмет |
| `/gamemode survival\|creative\|adventure` | Смена гейммода |
| `/heal` | Восстановить здоровье |
| `/feed` | Восстановить голод |

### Всегда запрещены

`/ban` `/kick` `/kill` `/op` `/deop` — заблокированы в обоих режимах.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| **P** | Открыть настройки ТГ-бота |

## Конфигурация

Файл `tgbot.json` в папке `.minecraft/`:

```json
{
  "token": "123456:ABC-DEF...",
  "chatId": 987654321,
  "mode": 2,
  "admins": [987654321]
}
```

## Сборка из исходников

```bash
# Нужен JDK 8+ (для тулчейна) и JDK 21+ (для Gradle)
git clone https://github.com/YOUR_NAME/tgbot.git
cd tgbot
./gradlew build
# jar будет в build/libs/
```

## Требования

- Minecraft 1.16.5
- Fabric Loader 0.14+
- Fabric API 0.42.0+1.16
- Java 8+ (для запуска игры), Java 21+ (для сборки)
